¿Que es Pop it?

Poo it se traduce literalmente como "reventarlo". Es un juego infantil cuyo proceso se puede comparar con reventar burbujas de plástico. Pero a diferencia del plástico de burbujas, los Pop-its se pueden apretar con la caracteristica, sensacion y sonido "infinito": docenas de burbujas de silicona simplemente se expulsan en la dirección opuesta.

Reglas del juego

los jugadores se turnan para presionar los granos. Deben completar la fila que empezaron. Se puede presionar maximo de tres granos a la vez (deben estar contiguos; no se pueden presionar varios granos a la vez a menos que este uno al lado del otro). El objetivo es que el oponente sea el ultimo en presionar. !El ultimo jugador en presionar pierde¡
